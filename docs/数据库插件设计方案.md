# dsh-database 插件功能清单

> 面向日常开发的数据库插件，复用 `dsh-remote-exec` 已验证的命令行校验模型。
> 本文件只列**要做哪些功能**，不含实现细节。
> 产品要求：界面必须美观，功能操作简单、不繁琐，覆盖日常开发中的大部分数据库操作；一期范围与验收以[一期版本计划](./数据库插件一期版本计划.md)为准。

---

## 一、连接管理

### 1. 多数据库连接
- 优先支持 MySQL / Oracle；后续扩展 PostgreSQL / SQLite / MSSQL / ClickHouse，同一套上层接口按方言注册
- 一个对话可同时连多个库、多个环境，连接互不干扰

### 2. 会话隔离
- 连接归属当前 DSH 对话，跨对话不可见、不可复用

### 3. 凭据与安全连接
- 凭据安全存储与使用，不明文外泄
- 支持 SSH 隧道连远程库
- 连接池复用，空闲自动回收

### 4. 只读连接加固
- 只读会话在数据库层强制只读，杜绝绕过

### 5. 连接便利
- 粘贴 DSN / `.env` / compose 片段自动拆解连接字段
- 自动发现本地连接（凭据不落盘、不进 AI 上下文）
- 断线自动重连，重连后重新核验身份

### 6. 驱动打包
- 一期优先集成 MySQL / Oracle 驱动，具体版本、运行模式及客户端依赖经验证后确定
- 后续数据库驱动按需扩展；任一驱动缺失或初始化失败不影响其他适配器，给出可操作提示

---

## 二、SQL 执行

### 7. 脚本执行
- 单语句执行
- 多语句脚本，事务包裹，失败自动回滚
- 迁移式幂等执行（已跑过的不重复跑）

### 8. 执行安全闸
- 写操作影响行数超阈值自动回滚
- 执行前可生成数据快照

### 9. 事务保护与错误翻译
- 事务进入错误状态后拒绝后续语句，避免 AI 无脑重试
- 数据库错误码翻译成可读说明，并标注是否可重试

---

## 三、AI 受控操作

### 10. AI 操作策略门
- AI 发起的每条语句先过策略判定：只读直接跑、写操作走人工审批、毁灭性操作硬拒绝
- AI 的自述只能抬高风险，不能降低；未知语句一律 fail closed

### 11. 自然语言转 SQL
- NL2SQL 生成草稿；生成与执行是两道独立的门
- 分级 schema 上下文 + 语义标注；表名不在上下文就拒绝，绝不猜
- schema 注释/数据内容按"不可信数据"处理，不当指令执行

### 12. AI 辅助 SQL 审查
- 对 SQL 给出可读的风险与语义说明，辅助人工判断

---

## 四、环境与数据保护

### 13. 多环境护栏
- dev / test / staging / prod 分级策略，生产策略只能收紧不能放宽
- 连接身份核验，防连错库
- 区分只读副本与主库
- 跨环境数据流动受控（单次、双端审批）
- 生产连接 UI 常驻红色标识，审批需二次确认

### 14. 结果脱敏
- 数据进入 AI 上下文前脱敏，覆盖所有出口（结果、错误消息、日志、预览）
- AI 侧永远拿脱敏结果，无揭示开关
- 诚实标注残留风险

---

## 五、结构与数据

### 15. 结构对比与同步
- Schema Diff，差异按破坏性分级
- 生成迁移 DDL（拓扑排序），作为待审草稿
- 方言差异无法可靠转换时明确标注，不假装转对
- DDL 反向工程 / 数据字典导出

### 16. 测试数据生成
- 按表结构生成测试数据
- 从生产采样生成 seed：FK 拓扑自洽、prod 来源强制脱敏

### 17. 数据修复
- 误操作后从执行前快照生成反向修复脚本（待审，不自动执行）

### 18. 导入导出
- 查询结果导出多种格式

---

## 六、诊断与巡检

### 19. 性能诊断
- 慢查询 Top-N 采集
- EXPLAIN 解析与索引建议（待审草稿，绝不自动建索引）
- 锁与阻塞树分析
- 长事务巡检

### 20. 运行巡检
- 连接数水位、表膨胀、复制延迟、无效索引、序列耗尽等健康检查

---

## 七、开发便利

### 21. Schema 智能感知
- 本地元数据缓存，秒答"哪些表有某字段"
- JOIN 路径靠外键图谱查找，无关联就明说、绝不瞎猜
- INSERT / SELECT 脚手架、孤儿外键检查

### 22. 跨方言 SQL 翻译
- PG ↔ MySQL 互转（分页、UPSERT、JSON、字符串拼接、RETURNING）
- 不等价处明确标注，只产草稿，执行仍走策略门

### 23. 数据类型保真
- 大数一律字符串（防 JS Number 精度丢失）
- 时间带时区，NULL / 空串 / "null" 严格区分

### 24. 查询工作台
- 结果转 INSERT / 转 Markdown
- 列统计、结果钉住对比

---

## 八、效率与界面

### 25. 查询历史与书签
- 历史可检索、可收藏

### 26. 结果集对比
- 多次查询结果横向对比

### 27. 审计日志
- 记录谁、何时、对哪个连接做了什么

### 28. 人类可视面板
- 复用 terminal 面板范式：SQL 控制台 + 风险高亮 + 结果网格
- 人机共享同一连接
- 界面与 DSH 主题协调，连接/对象导航、SQL 编辑和结果展示布局清晰，适配窄面板及明暗主题
- 常用操作就近可达，记住当前对话的选择和草稿；只读查询直接执行策略校验，写入集中审阅后一次批准执行
- 一期提供表/字段搜索、数据筛选排序分页、SQL 高亮/格式化/结构补全、查询标签页、历史模板及脱敏结果复制导出
- 用真实开发任务、操作步数及视觉走查验收，不能只验接口能否调用

---

## 非目标

- 不做通用数据库管理客户端（不追求 DBeaver 级 ER 图、可视化数据编辑网格）
- 不做数据同步 / ETL 编排引擎——跨环境搬运只是单次、双端审批
- 不自行开发 SQL 编辑器；格式化、补全和语法高亮优先复用宿主能力，缺失时集成兼容的成熟组件，不能因此省略基础编辑体验
- 不自动执行任何结构变更，索引建议、迁移 DDL 一律是待审草稿
- 不承诺支持所有方言的所有语法，解析失败即 fail closed，宁可多问一次
