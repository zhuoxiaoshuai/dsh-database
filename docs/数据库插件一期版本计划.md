# dsh-database 一期实施基线（已批准）

本文件按 2026-09-14 用户批准计划更新；替代原版本中“人工结果必须脱敏”和“DDL 不在一期范围”的约束。当前开发包为 alpha，不代表一期完成。

## 交付与兼容性

正式交付必须是经 Harness CLI 安装的版本化 tgz；独立网页仅用于开发。首个目标为 Windows DSH Desktop 0.8.0 / Harness 0.1.2-rc.1 / web profile。执行期间观察到 Desktop 升级为 0.8.2，分别记录验证，不混用结论。MySQL 以 8.0.32 为验收目标；8.4.5 临时库只用于机制验证。Oracle 19c 待实际环境核实，Oracle Free 23 不替代 19c。

采用正式 Cordis / Harness 类型，宿主 ESM，客户端使用 window.__ModuleLoader__.load factory 并复用宿主 React。包声明 dsh.bundle、dsh.client、cordis.patch.yml；资源与 Worker 从安装包相对定位。不修改宿主核心或安装目录，不发布空 invariant 入口。路由、工具、插槽、监听、定时器、连接与 Worker 随插件释放。

## 界面与日常功能

左侧连接与数据库/Schema/表/视图导航，中间工作区，右侧详情可收起。明暗主题、420/768/1200px、键盘和缩放必须验收，不能破坏聊天与 remote-exec 终端。

- 连接：添加、测试、编辑、断开、删除，密码不回显；版本、主机、端口、账号、服务、状态。
- 目录：按需加载、100 项分页、刷新、表名与字段搜索，元数据缓存 60 秒。
- 数据库详情：字符集、排序规则、对象数量、可见对象容量；Oracle 服务、Schema、表空间分别呈现。
- 表详情：注释、估算行数、数据/索引/总大小、引擎/表空间及可取得的时间；统计来源、采集时间、估算性质必须标明。无权限/不适用不显示为零。精确计数由用户主动触发。
- 结构：字段类型、长度、精度、默认值、空值、注释、自增/Identity、主外键、唯一/检查约束、索引与建表定义。
- 数据浏览：双击表加载首页，服务端筛选、排序、分页，可查看生成 SQL；缺少可靠唯一排序时提示一致性限制。
- 编辑器：多标签、高亮、结构补全、格式化、当前/选中单条语句执行、取消、历史与模板。
- 结果：网格、整行详情、JSON/XML 格式化/折叠/搜索/换行、原值复制、CSV/JSON 导出。保留精确数字、NULL、空串、时间语义；非法格式回退原文，XML 禁止外部实体，内容不执行 HTML。

## 查询与人工 / AI 边界

请求绑定真实对话、连接代次、数据库/Schema 与对象；编辑、重连、结构变化撤销旧请求与审批。人工展示有权读取的原值；AI 采用独立脱敏出口，未配置规则的业务数据不进入模型。凭据不写配置、日志、历史或模型。

默认 100 行，最多 500 行 / 编码后 1 MiB / 总期限 30 秒；LOB 按需限量读取。MySQL / Oracle 分别使用 AST、对象及函数策略，结合实证数据库只读措施。支持 SELECT、JOIN、聚合、HAVING、子查询、CTE、UNION、窗口；函数覆盖聚合、CASE、COALESCE/NULLIF、CAST、字符串转换、ROUND/ABS、DATE_FORMAT、TO_CHAR/TO_DATE/NVL、ROW_NUMBER/RANK/DENSE_RANK。

## 记录维护

新连接默认只读。生产/预发布只读，开发/测试须人工开启维护，不根据账号权限自动开启。字段表单新增，网格暂存或整行编辑，选择后删除预览。每次保存一条参数化 DML、一次确认、最多直接影响 100 行，超限回滚。可靠唯一键加并发校验，冲突保留草稿。无法确认触发器、级联、事务资格的目标不开放受控写入。

## 结构维护

支持建表、重命名、注释、增改删字段、索引/约束、删除表、清空表。审批前展示差异、完整 SQL、环境、依赖和数据损失；破坏性操作在同一窗口输入目标名。

审批仅人工可批准，绑定完整操作、对象、结构与连接代次；5 分钟有效、一次消费。每次最多 20 步，独立且无待提交 DML 的会话中串行执行，首错停止，区分成功/失败/未执行/未知；不承诺 DDL 整体回滚，不自动重试。可下载原始建表定义，明确不是数据备份。结构变化、锁等待、超时、断线后核验实际状态，无法确认保持未知。禁止系统对象维护、跨库级联删除、自动关闭约束、CASCADE/PURGE 和未验证依赖。

不包含删除数据库、用户权限管理、备份恢复、迁移、存储过程编辑或 BI。

## 顺序与必过门槛

1. 正式类型、打包、全新 profile CLI 安装。
2. 数据库/Schema、表结构、索引约束、容量。
3. 真实查询、筛选分页、格式化与导出。
4. DML、人工审批、并发校验、真实回滚。
5. DDL 编辑与有序分步执行。
6. 安装→重启→使用→升级→卸载→回退及共存验收。

每批先 MySQL 后 Oracle。写入和结构测试仅使用临时库；现有业务库只读核对。同权限对照 Navicat 对象、字段、索引和统计，解释来源/权限差异。验证类型、行数/容量上限、取消、权限、跨对话、重连和迟到结果；DML 回滚与冲突；DDL 部分成功/锁等待/断线/重复点击；缺失驱动与适配器独立失败；卸载重载资源释放。

安装先在独立 DSH_HOME 完成。现用 profile 安装前备份 manifest、锁文件、patch、旧 tgz，失败恢复。配置明确版本和迁移，凭据不落盘，卸载不改其他插件数据。分别记录自动化、隔离 Harness、现用 Desktop 结果。

**任何门槛未通过，不标记一期完成；页面可用不等于正式交付合规。**
