- SQL 高亮、结构补全、格式化及 Ctrl+Enter；原型仅对打开表时生成的预设 SQL 返回固定数据，自定义 SQL 明确提示尚无真实执行。
- 已加载演示结果的本地筛选与排序、单元格详情、Markdown 复制、CSV / JSON 导出。
- 运行期内存历史和模板；此处尚未实现持久化配置和模板。
- MySQL / Oracle 条件字段连接表单；已开放密码输入、测试连接与真实连接；MySQL 数据库及连接名称可选，Oracle Service Name / SID 必填其一。
- 演示连接旁提供删除入口，一次确认后清除对应查询标签页、草稿、结果、历史与模板；删除当前连接自动选中剩余连接，删除最后一个展示空状态。运行中的连接需先取消查询。删除仅作用于本次原型内存，刷新恢复演示连接，不修改数据库，也不代表已实现真实宿主连接删除。
- 一次“批准并执行”的写入审批交互原型；按钮明确标注演示，绝不执行写入。
- 弹窗局部键盘焦点循环、Esc 关闭及焦点恢复；不对宿主页面做全局焦点拦截。

原型的筛选、审批和结果不属于数据库业务验收，不能计作 D01–D10 或 A01–A33 的真实通过。原型固定数据不包含用户真实业务信息。

### 4.2 DSH 宿主验证骨架

- host 为 ESM，client 为 `window.__ModuleLoader__.load` factory；两侧按 DSH bundle manifest 接入。
- 包中不包含独立原型 fixture 或预览 HTML；真实 DSH 中不显示演示连接或数据。
- 真实宿主已注册通过宿主认证的人工连接接口；状态工具仍不接受凭据，`executionEnabled: false`。连接仅做固定身份读取，不开放用户 SQL 执行。
- 隔离宿主检查不需要模型配置，不会产生模型调用或数据库操作。

### 4.3 解析与驱动实验

- 分别识别 SELECT、JOIN、GROUP BY/HAVING、子查询、INSERT、UPDATE、DELETE、注释、字符串中的分号、非法语法与多语句。
- Oracle 绑定参数及 FETCH FIRST 样例、MySQL 参数和 LIMIT 样例通过；可将 Oracle 匿名块识别为非普通单条查询。
- 同时收集 Oracle lexer 和 parser 错误，不把错误恢复后的树视为无错误解析。
- 尚未实现对象授权、函数允许列表、事务资格或完整执行门禁；解析实验只在 `experiments/` 和测试中使用，不进入宿主执行路径。
- Oracle 解析移入独立 Worker，输入上限 16 KiB、期限最多 5 秒，配置 128 MiB 老生代/32 MiB 新生代/4 MiB 栈；超时和取消后终止线程。线程资源配置不等于整个进程的硬内存上限。复杂查询期间主线程定时器持续运行已验证。

### 4.4 审批状态契约与实库实验

- `src/approval-ledger.ts` 在服务端保存 SQL、绑定参数、连接/账号身份、结构版本、策略版本、方言和环境，客户端不能替换已审阅内容。
- 仅开发/测试环境可入队；审批 5 分钟有效、一次消费；其他对话不可读取、批准、拒绝或消费。连接变更、删除对话、身份/权限版本变化均使审批失效。
- 11 项审批契约单元测试通过，但尚未接入真实浏览器批准路由及 AI 工具，不能算完整审批验收。
- `scripts/mysql-acceptance.mjs` 自建并销毁带唯一任务标签的 MySQL 8.4.5 容器；验证 SELECT-only 账号、只读事务、大整数/金额保真、绑定、101 行回滚、单行提交、未变化行计数、元数据与流式截断。
- MySQL 12 项实库检查通过：同账号、SELECT-only 的独立控制连接执行 `KILL QUERY`，目标语句返回 `ER_QUERY_INTERRUPTED`，随后独立读取进程状态确认查询已结束。控制目标 ID 只取本次创建的连接，按十进制数字校验。
- 实验修正两处假设：启用大整数保真时 `CONNECTION_ID()` 返回字符串；单独 `SELECT SLEEP(...)` 被取消可正常返回 1，因此改用带表查询断言中断错误。后者与 [MySQL 8.4 官方文档](https://dev.mysql.com/doc/refman/8.4/en/miscellaneous-functions.html#function_sleep) 一致。不能仅靠客户端 timeout 宣称服务端取消。
- 写入测试只使用脚本创建的临时表。该实验未覆盖触发器、级联、非事务表及断线提交结果，不能把直接影响行数当成所有副作用上限。
- Oracle Free 23.26.2 的独立脚本完成 11 项 Thin 驱动检查：身份、NUMBER 字符串保真、只读账号/事务、101 行回滚、单行提交、未变化行计数、空串归 NULL、对象所有者元数据、ResultSet 限量读取和普通 SELECT 超时。普通 SELECT 在本次实测 115ms 返回 `NJS-123`，随后同连接查询成功；该结果不替代 Oracle 19c 或用户目标库验收。
- Oracle 实验曾出现两个差异：无 UPDATE 权限返回 `ORA-41900`，已按实际版本与 [Oracle 错误说明](https://docs.oracle.com/en/error-help/db/ora-41900/) 纳入拒绝断言；`DBMS_SESSION.SLEEP(10)` 在 `callTimeout=100` 下虽报 `NJS-123`，但返回超过 3 秒。未把该过程块标为及时取消通过；一期禁止程序块，普通 SELECT 的取消另行验证。正式执行器仍需独立的整体期限和资源回收机制，不能只设置 `callTimeout`。

### 局域网连接修复

### 编辑真实连接

连接列表增加铅笔入口，自动回填非敏感连接配置，密码保持空白。支持修改连接名称、方言、主机、端口、数据库/Service Name/SID、用户名和环境，以及编辑后的测试连接。密码需重新输入，不回显旧密码。

保存先建立新会话，成功才替换原连接并关闭旧会话，连接 ID 保持不变；失败不覆盖原配置和会话。服务端检查对话身份并串行处理同一连接的编辑；编辑期间删除原连接时，新会话不能将其复活。旧 Worker 退出回调不会删除已替换的新会话。达到连接上限时保留一个临时替换名额，成功后恢复上限。
